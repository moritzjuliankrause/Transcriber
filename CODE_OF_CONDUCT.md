# Code of Conduct

This is a small project, so this is short.

Be decent to each other. In issues, pull requests and any other discussion here,
treat people the way you'd want to be treated: assume good faith, disagree about
the code and not the person, and remember there's someone on the other end who
probably did this in their spare time.

That means no harassment, no personal attacks, no discrimination based on who
someone is, and no dragging in fights from somewhere else. Sharp, direct feedback
on the code is welcome and useful. Being a jerk about it is not.

If someone crosses that line, or you see something that makes this space feel
unwelcoming, email me at **moritz@moritz-krause.com**. I'll read it, keep it
private, and deal with it. Depending on what happened, that can mean a word to
the person, editing or removing a comment, or blocking someone from the project.
I'd rather never have to.

This applies anywhere the project lives: issues, pull requests, commit comments,
and any related channel.
